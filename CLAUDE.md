# Claude Code & Agentic Guidelines

Please refer to [AGENTS.md](AGENTS.md) for full architectural guidelines, development workflows, testing standards, and monorepo boundaries.

## Quick Reference
- **Build**: `npm run build`
- **Typecheck**: `npm run typecheck`
- **Test**: `npm test`
- **Dev**: `npm run dev`
- **Core Library**: `packages/core` (`@free-ai-gateway/core`)
- **MCP Server**: `packages/mcp` (`@free-ai-gateway/mcp`)
- **Skills Package**: `packages/skills` (`@free-ai-gateway/skills`)
- **CLI Package**: `packages/cli` (`@free-ai-gateway/cli`)
- **HTTP Gateway App**: `apps/gateway` (`@free-ai-gateway/gateway`)
